# GARDAVU

Application Windows locale Python 3.12, Tkinter, OR-Tools CP-SAT, SQLite et openpyxl.
Répondre en français. Lire les fichiers avant modification et utiliser apply_patch.
Ne jamais assouplir une contrainte impérative silencieusement. Le validateur métier
est indépendant du solveur. Un délai dépassé ne prouve pas une impossibilité.
Les horaires de semaine exigent une configuration explicite. Aucun réseau à
l'exécution, aucune donnée persistante dans _MEIPASS, AppData ou le registre.
Préserver les identités, l'historique effectif et les versions remplacées.
Les démonstrations sont fictives et séparées. Tester avec `.venv/Scripts/python -m pytest`.
Construire avec `./build_windows.ps1`. Ne revendiquer que les tests exécutés.
